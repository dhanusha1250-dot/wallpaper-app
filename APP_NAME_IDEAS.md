# App Name Ideas

Candidate names for the live / interactive wallpaper app. The current working
title is **Live Wallpaper Studio** (descriptive, but generic and likely
crowded on the App Store).

> **Before committing to a name, verify:**
> - App Store name uniqueness (App Store Connect rejects duplicates).
> - No conflicting trademark (search the USPTO / your local registry).
> - A usable domain is available (`.app`, `.com`).
> - Social handles are free.

## Top picks

| Name | Why | Watch out for |
|---|---|---|
| **Lumio** | Short, brandable, light-themed, easy domain odds | Verify trademark |
| **Driftly** | Calm + the "-ly" reads as an app name | — |
| **Kinetic** | Strong fit for an *interactive* wallpaper app | Common word — pair with a domain like `kinetic.app` |
| **Wallaby** | Memorable, friendly, built-in "wall" pun | — |
| **Auralis** | Premium, ties to the Aurora scene | Verify trademark |
| **Realm Desktop** | Future-proof if 3D models become a core feature | — |

**Recommendation:** pick a short brandable name (Lumio / Driftly / Auralis)
and use a descriptive App Store *subtitle* for ASO keywords, e.g.
*"Lumio — Live & interactive wallpapers"*.
